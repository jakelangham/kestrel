% dambreak_errors).

nYpertile = 1

Parameters:

Erosion = Off
Deposition = None
Eddy Viscosity = 0

Solver:
T start = 0
T end = 40
Initial condition = dambreak_wet_ic/000000
cfl = 0.5
max dt = 1
Tile Buffer = 3
Height threshold = 1e-6

Output:
N out = 4
directory = dambreak_wet/
